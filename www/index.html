Details and developer notes

      
    
        
  • Interpreter and location configuration: config/default.conf
    • 
        
  • Server web root: ./www
    • 
        
  • Sessions: the demo uses cookie SESSIONID
    • 
        
  • If a CGI returns an empty body for 405 it is intentional (safer for the client)
    • 
  
  • PHP CGI demo: /cgi-bin/hello.php (requires PHP CGI configured in config/default.conf)
    • 
  
  • Session demo: /session_demo.html — demo pokazuje przypisanie identyfikatora sesji (cookie SESSIONID), odczyt/zapis wartości w sesji oraz zniszczenie sesji. Wszystkie karty/przeglądarki używają tej samej sesji dopóki cookie nie zostanie usunięte.
    • 
  
  • Uwagi bezpieczeństwa: obecny mechanizm nadaje i przechowuje identyfikator sesji po stronie klienta. To wystarcza dla demonstracji i testów, ale w środowisku produkcyjnym warto rozważyć: regenerację ID po uwierzytelnieniu, flagi Secure/HttpOnly/SameSite, wygasanie sesji, ograniczenia (IP/UA) z rozwagą, oraz CSRF tokeny. Dla izolacji "per-tab" można użyć sessionStorage lub dodatkowego tokenu per-tab przekazywanego w nagłówku.
