Session Demo

This page demonstrates the server-side session endpoints. It will call the following endpoints on the same origin:

  • /session/create — create a session and return a session id plus Set-Cookie
  • /session/set?key=<k>&value=<v> — set a value inside the session (requires cookie)
  • /session/get?key=<k> — read a value from the session (requires cookie)
  • /session/destroy — invalidate the session (requires cookie)
