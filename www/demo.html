Developer Notes

  • CGI: executed by configured interpreters (see config/default.conf)
  • Static files: served from ./www
  • Sessions: demo uses cookie SESSIONID
  • Error pages: custom 404/500 available in www/error_pages

Tip: use the demo UI to observe headers (Content-Type, Content-Length, Allow) and status codes returned by the server.
